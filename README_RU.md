# Кино на работе — загрузчик YouTube для Android v2

**Статус сборки:** исходники готовы, но APK пока НЕ собран и НЕ проверен на устройстве. Эта папка — не установщик Android.

## Оформление v2
- Над полем вставки ссылки — большой неоновый заголовок **«ВОТ ЧТО СЕГОДНЯ БУДУ СМОТРЕТЬ НА РАБОТЕ))»**.
- Дизайн: тёмно-фиолетовая карточка, яркий градиент жёлтый → розовый → голубой, свечение букв.
- Название приложения в лаунчере: «Кино на работе».

## Возможности
- Вставка ссылки YouTube, или отправка из приложения YouTube через «Поделиться».
- Выбор готовой дорожки видео со звуком либо только аудио.
- Скачивание через DownloadManager, прогресс, сохранение в «Загрузки/ЮТ Загрузчик».
- Выделяемый и копируемый журнал, поддержка вставки через Ctrl+V.
- Android 13 и новее.

**Ограничения:** 1080p/4K со звуком не реализованы: прямые готовые потоки обычно только до 720p. Приложение не обходит DRM, региональные и возрастные блокировки, приватность/авторизацию. У YouTube могут меняться методы выдачи видео. Скачивайте только материалы, на которые есть право.

## Сборка APK

### Android Studio на компьютере
1. Распаковать архив в **новую папку**, не поверх предыдущей версии.
2. Открыть папку с проектом в Android Studio.
3. Выбрать JDK 17 и Gradle 8.13 (если Gradle Wrapper отсутствует — Android Studio может предложить локальный Gradle).
4. Установить SDK Platform 36 и Build Tools 35.0.0. Потребуется интернет для зависимостей.
5. Сборка: `gradle :app:assembleDebug`.
6. Результат: `app/build/outputs/apk/debug/app-debug.apk`.

### GitHub Actions без Android Studio
1. Создать репозиторий на GitHub и загрузить в него все файлы и подпапки из архива (в том числе `.github/workflows/build-apk.yml`).
2. Во вкладке Actions выбрать **Build Android APK** → **Run workflow**. Если при загрузке файлов был push в main, процесс может стартовать автоматически.
3. Открыть завершённый запуск → Artifacts → `KinoNaRabote-v2-debug-APK`.
4. В скачанном архиве будет `app-debug.apk`.

В этом проекте нет собранного APK: инструкции выше описывают сборку, а не подтверждают её успех.

## Обновления
- От предыдущей версии проект распаковывать в новую папку.
- Не удаляйте старые рабочие архивы до проверки новой сборки; после успешной установки удалите устаревшие ZIP.
- Установка нового APK поверх старого требует одинаковой подписи и applicationId; при смене подписи может понадобиться удалить предыдущую установку.
